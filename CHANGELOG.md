## 0.1.0

- JSON-RPC client with password and API key authentication, session persistence.
- ORM helpers (search_read, paginated, name_search, read_group, create/write/unlink, copy, …).
- Attachments / binary / image helpers.
- `Odoo.init()` global instance, `OdooConfig.fromEnvironment()` / `fromMap()`.
- Typed `OdooRepository<T>` and `OdooRecord` JSON helpers.
- Typed exceptions, retry interceptor, masked request/response logging, domain builder.
